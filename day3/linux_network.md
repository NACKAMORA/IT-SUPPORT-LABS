# Network Diagnostics in Linux

## Problem
User reported possible network connectivity issues.

## Environment
Parrot OS Virtual Machine

## Steps Taken
1. Checked network interfaces using `ip a`
2. Tested internet connection using `ping`
3. Reviewed listening services using `ss -tulnp`

## Solution
Network connectivity was confirmed and active services verified.
